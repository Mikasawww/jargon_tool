## 配置说明

1. 克隆本项目到本地。
2. 复制 `.env.example` 文件并重命名为 `.env`。
3. 在 `.env` 文件中填入你自己的 DeepSeek API Key。
4. 运行 `pip install -r requirements.txt` 安装依赖。
5. 运行 `python main.py`。

## 設定手順

1. プロジェクトをローカルにクローンします。
2. `.env.example` ファイルをコピーし、名前を `.env` に変更します。
3. `.env` ファイルを開き、ご自身の DeepSeek API キーを入力してください。
4. `pip install -r requirements.txt` を実行し、依存関係をインストールします。
5. `python main.py` を実行してアプリケーションを起動します。
